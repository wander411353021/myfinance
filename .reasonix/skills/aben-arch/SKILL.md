# 阿笨投资理论心法(2026-08-26 从 272 篇文章学习)

## 一、股眼理论(核心概念)

- **股眼** = 每只股票走势中"影响未来走势的关键点/关键区域"(多数是区域)。类比"诗眼""画龙点睛"。
- 股眼细分:几个K线组合 / 一个形态 / 关键量 / 整个节奏一气呵成 / 深刻影响未来的一波。
- 所处空间不同,作用不同:盘底 / 启动前试盘 / 启动后洗盘 / 第一波后整理 / 贴线加速。
- **股性差异 → 股眼差异**:一气呵成(气贯长虹)vs 纠结犹豫 vs 长期整理。
- 训练法:缩小+观图(熟读唐诗三百首),建立每只股票"历史股眼档案"。

### 吸筹型 K 线组合(阿笨命名)
- **双阳型(金龙探海)**:连续两根大阳线(堆量)+ 吃掉大阳线 → 吸筹
- **墨龙探海(乌龙探海)**:同金龙探海,外表是阴线;量不需看阴阳,只看放量与累计换手

### 偏态走势
- 趋势向下中"突然放量+大涨"的 V 型波 = 偏态走势(偶发强势,与下跌趋势相反,力度大)

## 二、量价时空(堆量心法)

- **第一句:堆量比孤量重要**(孤量=单日放量,堆量=连续放量区,信息量大)
- **第二句:长期堆量分析比短期准确率更高**
- **第三句:量不配合均线,事倍功半;量配合均线看,事半功倍**
- 堆量意图:①吸货 ②试盘 ③为后面小阴小阳洗盘留战略空间/争取时间(修复均线)
- **资金异动判断**:拉高四连阴放量 = 主力吸货(不是出货);堆量区域吸货居多
- 成本区分析:小量堆=开始介入(筹码不够)→ 大量堆=第一批主要介入/成本区 → 洗盘低点一般在成本上轨附近

## 三、黄金坑(与我们的算法直接对应)

阿笨"黄金坑"特征(华鼎系案例):
1. 前期有庄股特征走势(持续稳定行情)
2. **挖坑迅速而暴烈**:连续大幅下挫/跌停,几个交易日吞没前期大部分涨幅 → 对应我们的"快启动/短坑"
3. **坑底横盘**:长时间横盘震荡,振幅大幅缩小,K线近似直线
4. **横盘期有一定放量/堆量**:量能从大到小(对应"横盘蓄势 + 量堆")
5. **启动期量价恢复正常**

- 坑底横盘 + 堆量 = 蓄势确认(阿笨:坑肯定需要放量)
- 黄金坑填平后涨势不终止(百圆裤业坑后 30 日近 4 倍)

## 四、游资/短线模式(双响炮等)

- **双响炮(四环生物模式)**:1次拿货堆量 + 1次试盘拿货,两次整体换手 50%+;
  两次都是大阳线/双涨停;每次大阳线被吃掉;启动前 3 天连续略放量 + 大阳/涨停启动;
  启动后连续放爆量一气呵成,出货以跌停/大阴线
- **大阳+仙人指路**(=丹凤朝阳):涨停/大阳(1-2根)+ 长上影(阴阳不论)+ 小堆量;
  吃掉该组合后回压压力线;技术套利:从小放量介入到突破

## 六、股眼量化研究(2026-08-26,用户定义:股眼 = 改变走势的关键量堆)

### 定义(用户拍板)
- **股眼 = 关键的量堆,改变走势的量堆**(不是 K 线形态,是成交量堆)
- 股眼是"承上启下的关键节点":上承旧趋势终结,下启新趋势酝酿;**不代表马上主升**(酝酿期可长达数月,如 300437 4/12 吸筹堆 → 9 月主升)

### 识别实现(aben_patterns.py detect_guyan v2)
- 基于量堆(detect_volume_clusters)+ 走势确认,四类:
  - `reversal` = 堆前60日跌>8% + 堆后止跌(post>-3%,放宽版,识别吸筹堆)
  - `breakout` = 堆前横盘(±8%) + 堆后涨>8%
  - `accel` = 堆前已涨>8% + 堆后加速
  - `mega_absorb` = 峰值量比>8 巨量堆(纯吸筹)
- 返回 [(堆起点, 堆终点, 前段涨跌, 后段涨跌, 类型, 峰值量比)]
- 验证案例:300437 20210412(峰值16.5,前-19%→后+8% 止跌=S2吸筹)✓
  300251 20241028(→+164% S4)✓ 300204 20250407(→+33%)✓

### 标定结果(400 只随机样本,放量堆 6033 个)
- **真股眼率(堆后见 30%+):窗口 60日=18.5% / 120日=32.1% / 250日=47.8%**
  → 股眼"启下"时间跨度长,短窗口衡量失真;一年内近半数放量堆改变走势
- **前瞻因子(无未来函数):峰值量比无效(20.8% vs 基线 20%)**
  **深回撤有效(回撤<-40% → 31.6%,×1.6;峰值>8+回撤<-40% → 34.5%,×1.7)**
  → 和主升预测结论同源:"位置"决定量堆价值,量堆强度不重要

### 股眼定位(与黄金坑体系的分工)
- **股眼(放量堆,长期影响 47.8%)→ 观察/长期跟踪,非买入信号**
- **黄金坑+快启动+放量堆(93%)→ 精准买入信号**
- 三段式:股眼标记(长期) → 黄金坑确认(启动) → 买入

## 七、心法总结(实战要点)

1. **量是核心**:堆量 > 孤量,长期量 > 短期量,量+均线 > 单看量
2. **位置决定性质**:盘底/试盘/洗盘/整理/加速,同样形态在不同位置意义不同
3. **吸筹三信号**:放量堆(尤其被吃掉的大阳线)、拉高后放量阴线、堆量区域
4. **黄金坑完整流程**:庄股走势 → 暴烈挖坑 → 坑底横盘缩量 → 横盘堆量 → 放量启动
5. **推演 vs 预测**:阿笨强调"推演未来"(图形看多了能推演),但统计上主升事前难测(我们验证 23% 上限)
6. **一招鲜**:找到自己熟悉的有感觉的形态,训练到条件反射
7. **技术只是子系统**:技术+基本面+比价关系(缠师三系统),勿神圣化技术
