# 黄金坑策略 (Golden Pit Strategy)

A股超跌反弹量化策略。信号 = 股价深度跌破250日对数回归线形成坑 + 快速收复出坑。

## 回测结论（1000只A股，1206信号，2022-2026）

| 指标 | 值 |
|---|---|
| 20天持有全周期胜率 | **81.2%** |
| 60天持有全周期胜率 | 70.4%（弱市崩塌，不推荐） |
| 20天持有均值收益 | 9.2% |
| 甜点区(42-51分)胜率/均值 | 76% / 20% |
| 各年份20天胜率 | 2023:86.5% 2024:78.1% 2025:85.8% 2026:79.7% |

**核心结论**：60天持有是弱市胜率崩塌的元凶（2023:44%、2026:35%）；20天持有穿越牛熊。评分排序能识别甜点区，但极端高分（≥52）胜率崩塌需放弃。

## 信号定义（v1黄金坑）

1. 坑：收盘价相对250日对数回归线残差 z-score < -1.5（60日滚动std）
2. 快启动：坑底(b)到出坑(lch) ≤ 5 个交易日
3. 坑长：b - s + 1 ≥ 8 个交易日
4. 出坑：收盘收复 回归线×0.9 且 > 坑底×1.02
5. 买入：出坑日收盘价
6. 卖出：持有 20 个交易日

## 6 维度质量评分（0-100）

| 维度 | 分值 | 逻辑 |
|---|---|---|
| 缩量挖坑 | 25 | 坑内均量/坑前20日均量 < 0.7 为洗盘充分 |
| 放量出坑 | 25 | 出坑日量/前5日均量 ≥ 1.2 为放量确认 |
| 坑深适度 | 15 | 坑底较坑前60日最高跌幅 15%-50% 最佳 |
| 个股相对强度 | 15 | 个股20日涨幅 - 沪深300 20日涨幅 |
| 回归线方向 | 10 | 250日回归线斜率向上 |
| 坑底缩量 | 10 | 坑底附近缩量企稳 |

## 执行规则

| 评分 | 动作 |
|---|---|
| ≥ 52 | **放弃**（收益弹性大但胜率崩塌至59-62%） |
| 42-51 | **加仓**（甜点区，胜率76%、均值20%） |
| 30-41 | 正常仓位 |
| < 30 | 观望（低质量） |

## 使用方式

```bash

# 扫描股票池（默认300只）

# 全市场1000只
python3 scripts/golden_pit_final_strategy.py scan --pool scripts/stock_pool_1000.txt
```

## 数据说明

- 数据源：新浪财经日K线（`fetch_kline_sina`，无需代理，自动清除代理环境变量）
- 每只股票1023天数据（约4年），需 ≥310 天（250回归 + 60std）才能产生有效信号
- 相对强度需沪深300数据（自动获取并缓存）
- 接口有风控（HTTP 456），大量扫描时脚本内置随机sleep节流

## 注意事项

1. 次新股（<310天）无信号——数据长度依赖，这是算法已知盲区
2. 慢跌/阴跌场景检测不到（回归线同步下移，残差不深）——算法已知局限
3. 2026弱市环境下信号胜率会低于历史均值，建议结合大盘60日线仓位管理（大盘空头时减半仓）
4. 评分≥52的信号务必放弃，不要追高分化坑

## 交叉验证(2026-08-27,本地 eltdx 数据)

**验证目的**:6维评分层 vs 放量堆确认层,哪个更有效。

**样本**:本地 panic_reversal.detect_golden_pit(同口径 z<-1.5+快启动≤5+坑长≥8)
- 300 池:185 信号 | 1000 池:588 信号(2024-2026)

**结果(1000 池,20日胜率):**

| 分组 | n | 20日胜率 | 20日均值 | 60日胜率 |
|---|---|---|---|---|
| 基线(全部信号) | 588 | 88.4% | +11.6% | 70.9% |
| 评分 甜点区42-51 | 135 | 88.1% | +13.0% | 74.1% |
| 评分 放弃区≥52 | 122 | 84.4% | +9.2% | 63.1% |
| **放量堆确认** | **82** | **97.6%** | **+21.9%** | **90.2%** |
| 无放量堆确认 | 506 | 87.0% | +10.0% | 67.8% |
| 甜点区+放量堆 | 17 | 100.0% | +24.5% | 88.2% |
| 非甜点+放量堆 | 65 | 96.9% | +21.2% | 90.8% |

**结论(本地数据,两种池一致):**
1. **6维评分层本地不成立**:甜点区 88.1% ≈ 基线 88.4%,各区间 84-91% 无排序能力;
   v2.0 声称"甜点区76%/均值20%"在新浪+1206信号口径下未复现(可能 rs 维度/数据源差异,但平移不影响排序结论)
2. **放量堆确认层强有效**:97.6% vs 88.4%(+9.2pp),均值翻倍;60日仍 90.2%(超高信号稳定)
3. **评分不增加决策价值**:放量堆确认独立有效(非甜点+放量堆 96.9%);甜点区+放量堆 100%(n=17 小样本)
4. **执行建议**:以放量堆确认(出坑后7天巨量堆,峰值≥5)为主要决策层;6维评分仅作参考,不作加仓依据

**备注**:交叉验证脚本 `cross_validate_score_vs_pile.py`(本地)/ `cross_validate_1000.py`(1000池)

## 策略定版(2026-08-27 用户决策:A. 20日持有)

- **基准执行:黄金坑信号(快启动≤5 + 坑长≥8 + 出坑确认)出坑日买入,20 日持有**
  - 1000池 588 信号:20日胜率 88.4%、均值 +11.6%(2024:97.1% / 2025:87.9% / 2026弱市:84.0%)
  - 无需确认层即可高胜率;简单、换手快
- **放量堆确认(出坑后7天巨量堆峰值≥5)= 加仓/增强选项,非必要条件**:
  - 20日 97.6% / 均值+21.9%(锦上添花)
  - 60日 90.2%(若想延长持有到60日,必须有放量堆确认防弱市崩塌)
- **60日持有(无确认)= 禁用**:基线 70.9%,弱市崩塌(2023:44%/2026:35%)
- **6维评分 = 不采用**(本地数据无排序能力,甜点区 88.1% ≈ 基线)

## 组合验证:黄金坑 + reg 上行(2026-08-27,1000池588信号)

| 分组 | n | 20日胜率 | 60日胜率 |
|---|---|---|---|
| 基线(全部) | 588 | 88.4% | 70.9% |
| **reg 上行** | 158 | **94.9%** | 76.6% |
| reg 下行 | 430 | 86.0% | 68.8% |
| reg上行+放量堆 | 16 | 93.8% | 93.8% |
| **reg上行 无放量堆** | 142 | **95.1%** | 74.6% |
| **reg下行+放量堆** | 66 | **98.5%** | 89.4% |
| reg下行 无放量堆 | 364 | 83.8% | 65.1% |

**结论:**
1. **reg 上行是有效过滤器**(20日 94.9% vs 下行 86.0%,+8.9pp;占 27% 信号)
2. **放量堆确认对 reg 下行组增益最大**(83.8%→98.5%,+14.7pp;60日 89.4%)——下行趋势中的坑必须有强确认
3. **20日持有推荐过滤**:reg 上行 OR 放量堆确认(两者其一即 ~95%+;reg 上行 n=158 无需放量堆,下行需放量堆)
4. 回踩坑探索结论:reg/ma/cost 三种回踩形态 20日胜率 45-53%,无独立价值,不采用(见 explore_pullback_pit.py)
