# 黄金坑策略 (Golden Pit Strategy)

A股超跌反弹量化策略。信号 = 股价深度跌破250日对数回归线形成坑 + 快速收复出坑。

## 回测结论（1000只A股，1206信号，2022-2026）

| 指标 | 值 |
|---|---|
| 20天持有全周期胜率 | **81.2%** |
| 60天持有全周期胜率 | 70.4%（弱市崩塌，不推荐） |
| 20天持有均值收益 | 9.2% |
| 甜点区(42-51分)胜率/均值 | 76% / 20% |
| 各年份20天胜率 | 2023:86.5% 2024:78.1% 2025:85.8% 2026:79.7% |

**核心结论**：60天持有是弱市胜率崩塌的元凶（2023:44%、2026:35%）；20天持有穿越牛熊。评分排序能识别甜点区，但极端高分（≥52）胜率崩塌需放弃。

## 信号定义（v1黄金坑）

1. 坑：收盘价相对250日对数回归线残差 z-score < -1.5（60日滚动std）
2. 快启动：坑底(b)到出坑(lch) ≤ 5 个交易日
3. 坑长：b - s + 1 ≥ 8 个交易日
4. 出坑：收盘收复 回归线×0.9 且 > 坑底×1.02
5. 买入：出坑日收盘价
6. 卖出：持有 20 个交易日

## 6 维度质量评分（0-100）

| 维度 | 分值 | 逻辑 |
|---|---|---|
| 缩量挖坑 | 25 | 坑内均量/坑前20日均量 < 0.7 为洗盘充分 |
| 放量出坑 | 25 | 出坑日量/前5日均量 ≥ 1.2 为放量确认 |
| 坑深适度 | 15 | 坑底较坑前60日最高跌幅 15%-50% 最佳 |
| 个股相对强度 | 15 | 个股20日涨幅 - 沪深300 20日涨幅 |
| 回归线方向 | 10 | 250日回归线斜率向上 |
| 坑底缩量 | 10 | 坑底附近缩量企稳 |

## 执行规则

| 评分 | 动作 |
|---|---|
| ≥ 52 | **放弃**（收益弹性大但胜率崩塌至59-62%） |
| 42-51 | **加仓**（甜点区，胜率76%、均值20%） |
| 30-41 | 正常仓位 |
| < 30 | 观望（低质量） |

## 使用方式

```bash
# 单股扫描
python3 scripts/golden_pit_final_strategy.py scan --symbol sh600000

# 扫描股票池（默认300只）
python3 scripts/golden_pit_final_strategy.py scan --pool scripts/stock_pool_300.txt

# 输出指定日期的信号（当日可执行列表）
python3 scripts/golden_pit_final_strategy.py signals --pool scripts/stock_pool_300.txt --date 2026-08-27

# 全市场1000只
python3 scripts/golden_pit_final_strategy.py scan --pool scripts/stock_pool_1000.txt
```

依赖模块：
- `scripts/golden_pit_v2_backtest.py`（数据获取 + 信号检测，自动被引用）
- 股票池：`scripts/stock_pool_300.txt`（300只） / `scripts/stock_pool_1000.txt`（1000只）

## 数据说明

- 数据源：新浪财经日K线（`fetch_kline_sina`，无需代理，自动清除代理环境变量）
- 每只股票1023天数据（约4年），需 ≥310 天（250回归 + 60std）才能产生有效信号
- 相对强度需沪深300数据（自动获取并缓存）
- 接口有风控（HTTP 456），大量扫描时脚本内置随机sleep节流

## 注意事项

1. 次新股（<310天）无信号——数据长度依赖，这是算法已知盲区
2. 慢跌/阴跌场景检测不到（回归线同步下移，残差不深）——算法已知局限
3. 2026弱市环境下信号胜率会低于历史均值，建议结合大盘60日线仓位管理（大盘空头时减半仓）
4. 评分≥52的信号务必放弃，不要追高分化坑
