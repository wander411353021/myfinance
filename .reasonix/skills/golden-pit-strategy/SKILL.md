A股超跌反弹量化策略。信号 = 股价深度跌破250日对数回归线形成坑 + 快速收复出坑。

## 回测结论（1000只A股，1206信号，2022-2026）

| 指标 | 值 |
|---|---|
| 20天持有全周期胜率 | **81.2%** |
| 60天持有全周期胜率 | 70.4%（弱市崩塌，不推荐） |
| 20天持有均值收益 | 9.2% |
| 甜点区(42-51分)胜率/均值 | 76% / 20% |
| 各年份20天胜率 | 2023:86.5% 2024:78.1% 2025:85.8% 2026:79.7% |

**核心结论**：60天持有是弱市胜率崩塌的元凶（2023:44%、2026:35%）；20天持有穿越牛熊。评分排序能识别甜点区，但极端高分（≥52）胜率崩塌需放弃。

## 信号定义（v1黄金坑 / 规则F 2026-08-28 定版）

1. 坑：收盘价相对250日对数回归线残差 z-score < -1.5（60日滚动std）
2. 快启动：坑底(b)到出坑(lch) ≤ 5 个交易日
3. 出坑：收盘收复 回归线×0.9 且 > 坑底×1.02
4. 买入：出坑日收盘价
5. 卖出：持有 20 个交易日

**规则F（2026-08-28）**：移除「坑长≥8」约束——坑长<8 的急跌急涨V型短坑胜率反而更高（详见下方"规则F放宽验证"）。快启动≤5 仍是核心约束，去掉后胜率掉到 65.8%（1000池 H 全收）。

## 坑段合并与出坑确认设计（2026-08-28 polo4111, 供 reasonix 审查设计合理性）

**函数签名**: `detect_golden_pit(closes, reg250, z_thr=-1.5, merge_gap=15, launch_gate=0.9, use_pre_std=True)`

**坑段合并规则(merge_gap=15)**:
- 坑段 = z-score < -1.5 的连续段(60日滚动std; pass1 用含坑std粗定, pass2 用坑前std精定边界)
- 相邻两段(中间 z≥-1.5 的非坑日)若 **"后段起点 − 前段尾 ≤ 15 交易日"** 则合并为同一坑段
  (即中间最多隔 14 个非坑交易日); pass1 与 pass2 均执行该合并
- 合并只影响"坑段边界", 不影响出坑日选择(修复后出坑日 = 段起点后第一次收复门控线)

**出坑确认(2026-08-28 因果修复后)**:
- 从段起点 s+1 线性扫描, 实时维护"截至当天的段内最低价" b(只用≤当前日历史)
- 出坑日 lch = 第一个满足 **收盘 ≥ reg250×0.9 且 收盘 > 当天已知坑底×1.02** 的日子
- b 与 lch 均只用 ≤lch 数据确定(严格因果, 截断自检 989股×6截断点 0 不一致)
- 出坑确认后 break, 不再因后续下跌改判(旧版会因"出坑后创新低"把 lch 推迟到未来, 已修复为因果)

**设计意图(待 reasonix 审查)**:
1. 为何用"价格碰门控线(reg250×0.9)即出坑"而非"连续站稳/回踩不破"——单日碰线确认, 假出坑率高
   (修复后真实单信号胜率 51.6%, 均值 +1.68%, 接近随机; 假出坑 = 碰线后再度深跌)
2. 为何 merge_gap=15——出坑后 ≤15 天再跌破会合并为同一坑段而非新坑, 间隔>15 才算新坑
3. 用户核心质疑: "真出坑"应定义在**出坑逻辑本身**(连续站稳/回踩不破/W型确认), 而非事后特征过滤
   (放量堆已证伪 51.4%≈全部; reg上行仍有 edge 56.0% vs 50.1%)
4. 核心权衡: **确认强度(胜率) vs 入场成本(延迟/价格)**——更严确认→更晚入场→收益压缩
   (历史实测: 门控 0.9→1.0 胜率 79.7%→58.7% 追高反亏; 快启动≤5 是强约束, 去掉胜率掉到65.8%)

5. 待验证候选(严格因果框架下): 连续站稳N天 / 回踩不破(W型) / 站上短均线(MA5/10/AMA)替代碰门控线

### 坑长分层验证(2026-08-28 polo4111, 严格因果修复后全池3971信号) — 重要, 供 reasonix 审查

**数据**(全池2023+, 快启动lch-b<=5, 20日持有):
| 坑长(lch-s) | 信号数 | 20日胜率 | 均值 | 出坑后跌破坑底率 |
|---|---|---|---|---|
| 0~5天(短坑) | 2930 (74%) | 50.2% | +1.45% | **54.2%**(最差) |
| 6~10天 | 601 | 55.2% | +2.41% | 45.6% |
| 11~20天 | 295 | 53.6% | +1.85% | 43.7% |
| 21~40天(长坑) | 99 | **60.6%** | +3.35% | **27.3%**(最好) |
| 41+天 | 46 | 63.0% | +2.43% | 28.3% |

**关键结论(反转直觉)**:
1. **短坑(0~5天)才是假出坑重灾区**: 出坑后20日内跌破坑底率 54.2%(过半), 胜率仅50.2%
   ——急跌急涨V型大量是"跌太快→反弹一日游→再回落", 反复跌破最频繁
2. **长坑(21~40天)反而可靠**: 跌破率仅27.3%, 胜率60.6%——跌得久洗盘充分, 出坑后更坚定
3. ⚠️ **推翻skill旧结论**: "坑长<8的急跌急涨V型短坑胜率反而更高"(规则F放宽依据)是
   **未来函数污染前**的结论, 修复因果后被本数据推翻——短坑胜率反而最低
4. **正确方向**: 按坑型定制出坑确认强度——**短坑加"连续站稳2天"等强确认(过滤假出坑重灾区),
   长坑保持甚至放宽(本来就可靠, 别误伤)**; 比一刀切加严更精准, 信号量损失更小

## 未来函数自检(2026-08-28 polo4111,零容忍)

**方法**: 截断一致性验证——对每个信号,把 K线截断到出坑日 lch,重跑 detect_golden_pit,
          若信号仍复现则证明"lch 日收盘即可产生",无未来函数。脚本 `golden_pit_lookahead_check.py`。

**结论1: 核心链路无未来函数** ✅
- reg250/std/z-score/出坑判定/买入价(closes[lch]) 全部只用 lch 当日及历史
- 修复后截断验证 100% 通过(1186/1186, 0 幽灵)
- 实盘 signal() 只用当日及历史 ✅

**结论2: detect_golden_pit pass2 幽灵信号(0.8%)已修复** 🔧
- 根因: pass2 用"坑前std"重算坑段时,坑底被回溯到出坑日之前,而确认坑段的 pass1 起点
  在出坑日之后(例 sh600686 坑底394/出坑395,pass1坑段起点404)→ 出坑日无法产生该信号
- 修复: 两处(panic_reversal.detect_golden_pit + golden_pit_v2_backtest.detect_golden_pit_v1)
  加因果保护 `if lch is not None and lch < s0: continue`(出坑日不得早于pass1坑段起点)
- 影响: 幽灵信号 14/1761→0, 规则F胜率 80.4%→80.3%(剔除无效信号,结论不变)

**结论3: 放量堆加仓确认 = 未来函数,已推翻(重要!)** 🚨
- reasonix 的"放量堆确认 97.6%/93.2%" = 用出坑后7天放量堆选股、从出坑日(lch)算 r20 → 提前知道未来
- 真实可执行口径(确认后 lch+7 买入持有20日, 500只池 n=162):
  | 口径 | 胜率 | 均值 |
  |---|---|---|
  | 全体规则F | 82.4% | +7.73% |
  | super组 从lch算(未来函数) | 93.2% | +15.22% |
  | super组 从lch+7算(真实可执行) | **56.8%** | **+3.42%** |
- **结论: 放量堆不作加仓/买入依据(真实胜率低于不买),仅保留事后标注(金色★=历史确认区)**
- require_super=True 回测模式(backtest_golden_pit.py)禁止用于可执行统计,只作研究分组

### 回撤归因与降回撤方案(2026-08-28 polo4111, 估值修复后真实市价口径)

**估值修复**: 原 `total_asset()` 用**买入日价**估值持仓(资产曲线只反映已实现现金流, 不反映持仓浮亏) → 修复为**按当前日期市价估值**。同时修复同日快照被 sort 乱序导致假回撤的 bug。修复后真实最大回撤 **-15.1%**(2026-05-19 峰值850.9万 → 2026-07-24 谷底722.5万, 沪深300同期-4.2%)。

1. **弱市环境(主因)**: 回撤窗口恰逢沪深300 -4.2% 下跌段, 黄金坑是抄底策略, 弱市里"下跌中继被误判成坑"的假信号增多 → 窗口胜率仅 55%(vs 其他时段 72%)

4. **复利高位基数**: 峰值850万后, -15% 对应约128万绝对损失, 感受"巨大"
5. 窗口仍有结构韧性: 同期照样出 +37.9%/+32.3%/+29% 大赚票, 非全面失效
