A股超跌反弹量化策略。信号 = 股价深度跌破250日对数回归线形成坑 + 快速收复出坑。

## 回测结论（1000只A股，1206信号，2022-2026）

| 指标 | 值 |
|---|---|
| 20天持有全周期胜率 | **81.2%** |
| 60天持有全周期胜率 | 70.4%（弱市崩塌，不推荐） |
| 20天持有均值收益 | 9.2% |
| 甜点区(42-51分)胜率/均值 | 76% / 20% |
| 各年份20天胜率 | 2023:86.5% 2024:78.1% 2025:85.8% 2026:79.7% |

**核心结论**：60天持有是弱市胜率崩塌的元凶（2023:44%、2026:35%）；20天持有穿越牛熊。评分排序能识别甜点区，但极端高分（≥52）胜率崩塌需放弃。

## 信号定义（v1黄金坑 / 规则F 2026-08-28 定版）

1. 坑：收盘价相对250日对数回归线残差 z-score < -1.5（60日滚动std）
2. 快启动：坑底(b)到出坑(lch) ≤ 5 个交易日
3. 出坑：收盘收复 回归线×0.9 且 > 坑底×1.02
4. 买入：出坑日收盘价
5. 卖出：持有 20 个交易日

**规则F（2026-08-28）**：移除「坑长≥8」约束——坑长<8 的急跌急涨V型短坑胜率反而更高（详见下方"规则F放宽验证"）。快启动≤5 仍是核心约束，去掉后胜率掉到 65.8%（1000池 H 全收）。

## 坑段合并与出坑确认设计（2026-08-28 polo4111, 供 reasonix 审查设计合理性）

**函数签名**: `detect_golden_pit(closes, reg250, z_thr=-1.5, merge_gap=15, launch_gate=0.9, use_pre_std=True)`

**坑段合并规则(merge_gap=15)**:
- 坑段 = z-score < -1.5 的连续段(60日滚动std; pass1 用含坑std粗定, pass2 用坑前std精定边界)
- 相邻两段(中间 z≥-1.5 的非坑日)若 **"后段起点 − 前段尾 ≤ 15 交易日"** 则合并为同一坑段
  (即中间最多隔 14 个非坑交易日); pass1 与 pass2 均执行该合并
- 合并只影响"坑段边界", 不影响出坑日选择(修复后出坑日 = 段起点后第一次收复门控线)

**出坑确认(2026-08-28 因果修复后)**:
- 从段起点 s+1 线性扫描, 实时维护"截至当天的段内最低价" b(只用≤当前日历史)
- 出坑日 lch = 第一个满足 **收盘 ≥ reg250×0.9 且 收盘 > 当天已知坑底×1.02** 的日子
- b 与 lch 均只用 ≤lch 数据确定(严格因果, 截断自检 989股×6截断点 0 不一致)
- 出坑确认后 break, 不再因后续下跌改判(旧版会因"出坑后创新低"把 lch 推迟到未来, 已修复为因果)

**设计意图(待 reasonix 审查)**:
1. 为何用"价格碰门控线(reg250×0.9)即出坑"而非"连续站稳/回踩不破"——单日碰线确认, 假出坑率高
   (修复后真实单信号胜率 51.6%, 均值 +1.68%, 接近随机; 假出坑 = 碰线后再度深跌)
2. 为何 merge_gap=15——出坑后 ≤15 天再跌破会合并为同一坑段而非新坑, 间隔>15 才算新坑
3. 用户核心质疑: "真出坑"应定义在**出坑逻辑本身**(连续站稳/回踩不破/W型确认), 而非事后特征过滤
   (放量堆已证伪 51.4%≈全部; reg上行仍有 edge 56.0% vs 50.1%)
4. 核心权衡: **确认强度(胜率) vs 入场成本(延迟/价格)**——更严确认→更晚入场→收益压缩
   (历史实测: 门控 0.9→1.0 胜率 79.7%→58.7% 追高反亏; 快启动≤5 是强约束, 去掉胜率掉到65.8%)

5. 待验证候选(严格因果框架下): 连续站稳N天 / 回踩不破(W型) / 站上短均线(MA5/10/AMA)替代碰门控线

### 坑长分层验证(2026-08-28 polo4111, 严格因果修复后全池3971信号) — 重要, 供 reasonix 审查

**数据**(全池2023+, 快启动lch-b<=5, 20日持有):
| 坑长(lch-s) | 信号数 | 20日胜率 | 均值 | 出坑后跌破坑底率 |
|---|---|---|---|---|
| 0~5天(短坑) | 2930 (74%) | 50.2% | +1.45% | **54.2%**(最差) |
| 6~10天 | 601 | 55.2% | +2.41% | 45.6% |
| 11~20天 | 295 | 53.6% | +1.85% | 43.7% |
| 21~40天(长坑) | 99 | **60.6%** | +3.35% | **27.3%**(最好) |
| 41+天 | 46 | 63.0% | +2.43% | 28.3% |

**关键结论(反转直觉)**:
1. **短坑(0~5天)才是假出坑重灾区**: 出坑后20日内跌破坑底率 54.2%(过半), 胜率仅50.2%
   ——急跌急涨V型大量是"跌太快→反弹一日游→再回落", 反复跌破最频繁
2. **长坑(21~40天)反而可靠**: 跌破率仅27.3%, 胜率60.6%——跌得久洗盘充分, 出坑后更坚定
3. ⚠️ **推翻skill旧结论**: "坑长<8的急跌急涨V型短坑胜率反而更高"(规则F放宽依据)是
   **未来函数污染前**的结论, 修复因果后被本数据推翻——短坑胜率反而最低
4. **正确方向**: 按坑型定制出坑确认强度——**短坑加"连续站稳2天"等强确认(过滤假出坑重灾区),
   长坑保持甚至放宽(本来就可靠, 别误伤)**; 比一刀切加严更精准, 信号量损失更小

## 未来函数自检(2026-08-28 polo4111,零容忍)

**方法**: 截断一致性验证——对每个信号,把 K线截断到出坑日 lch,重跑 detect_golden_pit,
          若信号仍复现则证明"lch 日收盘即可产生",无未来函数。脚本 `golden_pit_lookahead_check.py`。

**结论1: 核心链路无未来函数** ✅
- reg250/std/z-score/出坑判定/买入价(closes[lch]) 全部只用 lch 当日及历史
- 修复后截断验证 100% 通过(1186/1186, 0 幽灵)
- 实盘 signal() 只用当日及历史 ✅

**结论2: detect_golden_pit pass2 幽灵信号(0.8%)已修复** 🔧
- 根因: pass2 用"坑前std"重算坑段时,坑底被回溯到出坑日之前,而确认坑段的 pass1 起点
  在出坑日之后(例 sh600686 坑底394/出坑395,pass1坑段起点404)→ 出坑日无法产生该信号
- 修复: 两处(panic_reversal.detect_golden_pit + golden_pit_v2_backtest.detect_golden_pit_v1)
  加因果保护 `if lch is not None and lch < s0: continue`(出坑日不得早于pass1坑段起点)
- 影响: 幽灵信号 14/1761→0, 规则F胜率 80.4%→80.3%(剔除无效信号,结论不变)

**结论3: 放量堆加仓确认 = 未来函数,已推翻(重要!)** 🚨
- reasonix 的"放量堆确认 97.6%/93.2%" = 用出坑后7天放量堆选股、从出坑日(lch)算 r20 → 提前知道未来
- 真实可执行口径(确认后 lch+7 买入持有20日, 500只池 n=162):
  | 口径 | 胜率 | 均值 |
  |---|---|---|
  | 全体规则F | 82.4% | +7.73% |
  | super组 从lch算(未来函数) | 93.2% | +15.22% |
  | super组 从lch+7算(真实可执行) | **56.8%** | **+3.42%** |
- **结论: 放量堆不作加仓/买入依据(真实胜率低于不买),仅保留事后标注(金色★=历史确认区)**
- require_super=True 回测模式(backtest_golden_pit.py)禁止用于可执行统计,只作研究分组

### 回撤归因与降回撤方案(2026-08-28 polo4111, 估值修复后真实市价口径)

**估值修复**: 原 `total_asset()` 用**买入日价**估值持仓(资产曲线只反映已实现现金流, 不反映持仓浮亏) → 修复为**按当前日期市价估值**。同时修复同日快照被 sort 乱序导致假回撤的 bug。修复后真实最大回撤 **-15.1%**(2026-05-19 峰值850.9万 → 2026-07-24 谷底722.5万, 沪深300同期-4.2%)。

1. **弱市环境(主因)**: 回撤窗口恰逢沪深300 -4.2% 下跌段, 黄金坑是抄底策略, 弱市里"下跌中继被误判成坑"的假信号增多 → 窗口胜率仅 55%(vs 其他时段 72%)

4. **复利高位基数**: 峰值850万后, -15% 对应约128万绝对损失, 感受"巨大"
5. 窗口仍有结构韧性: 同期照样出 +37.9%/+32.3%/+29% 大赚票, 非全面失效

### 第一波主升规律(2026-09-02 polo4111 发现, 全池验证)
- **定义**: 第一波主升 = 主升起点前120天内无其他主升(60日>40%)的独立启动波; 后续波 = 之前已有主升
- **全池5203主升段(1000只, 2022-2026)**: 第一波1276个(24.5%), 后续波3927个(75.5%)
- **第一波特征(用户观察验证)**:
  - reg250斜率向下: 72.9%(vs 后续波38.2%)
  - 价格在reg250下方: 83.6%(vs 后续波50.8%)
  - 偏离reg250中位: **-10.9%**(vs 后续波-0.5%)
  - 偏离<-10%: 52.0%, 偏离<-20%: 30.2%
  - 平均涨幅44.7%(vs 后续波51.3%), p90: 52% vs 65%
- **核心规律**: **第一波主升 = 深坑(偏离reg250中位-10.9%) + reg250斜率向下(72.9%) + 价格在reg下方(83.6%)**——即从远离reg250的深坑启动; 后续波 = 站上reg后的趋势加速(强势区)
- **涨幅差异原因**: 第一波是"转势"(深坑反转), 第二波是"加速"(趋势延续), 故后续波涨幅更大但追高风险大
- **对策略含义**: 黄金坑抓的正是第一波(深坑反转启动), 天然牺牲第二波涨幅; 第一波启动点偏离度-10%~0%占比最大(31.7%), 说明不一定要最深, 但一定在reg下方
- **格栅线目标价机制(2026-09-02)**:
  - 格栅线 = max(reg120, reg250) * (1+档位), 档位=+3/+6/+9/+12%(3%间隔)
  - **基准线是动态的**: max(reg120,reg250) 随每日数据滚动更新, 所以格栅线本身每天都在动(跟随reg)
  - **档位是静态的**: +3/+6/+9/+12% 是固定偏移比例, 不随行情动态调整
  - **站上某线后目标价仍会变化**: 因为基准线继续滚动更新(reg跟随价格上行), 格栅线上移; 但V10面板只显示+3%和+12%两条, 站上+3%后看的是+12%那根线(它会随reg上行而上移, 不会卡死)
  - 局限: 格栅是reg的百分比平移, 本质仍是"reg的包装", 不产生超越reg的独立信息; 用户已确认黄金坑为最优, 格栅仅作观察面板

### 阶梯式分段目标价 compute_grid_target_price(2026-09-02 polo4111)
- **签名**: compute_grid_target_price(closes, reg120, reg250, levels=(0.03,0.06,0.09,0.12), max_dev=0.20, down_confirm=5)
- **基准**: base = max(reg120, reg250)(两线取大, 与格栅线同一基准)
- **阶梯档位**: +3%/+6%/+9%/+12%(3%间隔), 目标价 = base*(1+levels[cur])
- **严格无未来函数(核心要求)**:
  - 每天目标价 = base[t]*(1+levels[cur]), cur 是**昨天收盘后确定**的状态
  - 当天收盘价只在收盘后更新状态(升/降档/置空), **只影响明天的目标价**
  - 当天价格不参与当天目标价计算
- **升档**: 收盘 >= base*(1+levels[cur]) 且未到最高档 -> cur+=1(当天确认, 次日生效)
- **降档(延迟确认防急降)**: 连续 down_confirm=5 天收盘 < base*(1+levels[cur-1]) -> cur-=1(2026-09-02 用户调: 3天→5天)
- **置空**: 收盘偏离 base > max_dev(默认+20%) -> 次日目标置NaN, cur重置0; 价格回归(偏离<=max_dev)后次日从+3%重新开始
  - 意义: 价格暴涨脱离reg后目标价失去意义(reg滞后追不上), 置空避免给出无意义低目标
- **V10接入(plot_v10_reg_smooth.py)**: 必须用与V10内部一致的 double_smooth_reg(5,5) reg 计算目标价, 否则目标价线与图上reg250线口径不一致(下跌段目标可能显示低于reg250)——曾出现此bug, 修复后0天目标<reg250
- **参数说明**: max_dev=0.20(偏离reg>20%置空), down_confirm=5(连续5天跌破才降档)

## ⭐ 入池时点重大修正: "要刚要进入主升的, 不是已经猛涨的"(2026-10-15 reasonix, 用户定版)
**背景**: 豆包原 `scan_pressure_breakout.detect` 入池条件 = 压制期 + 近20天**置空**(dev>13% 价格冲出压制半径) + 收>MA20。
用户质疑: "我需要的是刚刚要进入主升的, 而不是已经猛涨的" → 重新验证后**完全证实**, 原条件是买在猛涨之后。

### 定版条件(scan_pressure_breakout, mode='early' 默认)
```
① 压制期(150天): 线有效≥70% + 价格>线占比≤15% + 线-价中位 gap 10~25%
② 低位未启动: dev = 收盘/base - 1 < -10%      ← 还没猛涨
③ 启动确认: 今收 > MA20 且 昨收 <= MA20         ← "刚刚要进入主升"那一天
```
- `--void-mode` 可切回旧逻辑(置空突破后)。
- **命中率实测(989只快照)**: 仅①② 命中 6.1%(全市场约335只/日, 池子会爆); 加③后 **0.4%(约20只/日)** ✓ 规模合理。
- ⚠️ 待办: ③ 的预测力尚未回测(样本 4/989 太少), 需积累正向样本后再验证。

### 方法论教训(可复用)
1. **"确认型"信号必然滞后**: "等置空确认"= 等价格已涨 26.5% 才发出信号 → 后 60 日跑输基准(+4.5% vs 5.72%)。
2. **信号时点必须用"信号前涨幅"审视**: 只看"信号后收益"会把滞后信号误判为好信号(均值仍为正, 但跑输基准)。
3. **评价任何入场信号必须对比同期基准**(本次基准 = 全体满足压制期样本 +5.72%/51.9%)。
4. **命中率要落到"每日可操作只数"**: 6.1%/日 = 335 只 = 无法行动; 0.4%/日 = 20 只 = 可人工过一遍。

## 每日扫描池管理: 入池/出池/分级 (2026-10-16 polo4111 定版, 已入库)
- **运作结构**: 每日盘后 = ① 新增扫描(全市场找新 bigline/v3b 信号入池) + ② 池内复盘(跟踪已有信号状态, 确认或证伪)
- **入池**: 全市场 `scan_big <part> <nparts> <end>` fresh 信号 + 当日 v3b/early 信号 → 附画像入池
- **出池规则(任一命中即移出, 进归档)**:
  1. **质量甄别(改, 2026-10-18 reasonix 推翻后)**: ~~入池后 20 个交易日内未出现大阳确认 → 证伪移出~~ 大阳线只能做**事后质量甄别, 不能延迟入场**——入池当天(early 日)即参与(同批 early 当天买 +8.9% > 等大阳线 +2.5%); 20 日未出大阳的票整体质量差(>10%仅18.2% vs 出大阳组39.1%), 降级观察/可提前人工剔除, 但不等确认
  2. **量能证伪**: 大阳确认后 10 日相对量 <1.15 → 延续段缩量, 成功率30%中位+6.4%
  3. **结构破坏**: 收盘跌破 COST35(Ehlers45) 且 2 日未收回 → 主力成本线失守
  4. **到期归档**: 确认后满 60 个交易日强制移出(无论走势)
  5. **人工标记**: 人工看完标记"不关注"
- **池容量上界**: 单票最长在池 = 20(等确认)+60(跟踪)=80 交易日; 稳态容量 ≈ 每日新增×80(≈1600-3200只), 不无限膨胀
- **池内分级**: 待确认(<20天等大阳) / 跟踪中(已确认, 记回撤/量能/出池条件) / 已归档(证伪/到期/完结, 供复盘)
- **每日输出三块**: 新增入池 + 状态迁移(待确认→跟踪/证伪出池) + 归档复盘

## ⚠️ UTC 日期全局坑(2026-10-18 reasonix 修复, 豆包只修了一处)
- **现象**: `tdx` 返回的 `date` 是 **UTC 存储** —— 交易日 D 存成 **D-1 16:00**(实测 `2026-10-07T16:00` = 交易日 **10-08**)。
- **后果**: 任何 `str(date)[:10]` / `.dt.normalize()` 都会**早一天**:
  - 信号日期早一天、报告日期错;
  - 缓存新鲜度校验错位(请求 20261014 但数据到 20261012 → 永不复用缓存, 每次重拉);
  - `weekday<5` 周末过滤把**周一**当周日误删(UTC 下周一 = 周日)。
- 豆包只在 v3b 面板用 `challenge_scan._bd()`(+8h)修了**显示层**, 其余调用点仍错。
- **根治(已实施)**: `tdx_quant.get_daily_kline_from_tdx` / 周线接口统一
  `df['date'] = (pd.to_datetime(df['date']) + pd.Timedelta(hours=8)).dt.normalize()`
  —— 一次对齐全部下游(纯日期 00:00 的数据 +8h 后仍同一天, 无副作用)。
- 配套: 缓存校验改为"末端日期够新 **或** 缓存 12 小时内拉过"(通达信常滞后于请求日)。

**结论**:
1. **"等第一根大阳线再买"是负价值** —— 同批样本内 early 当天买(+8.9%)显著优于等大阳线(+2.5%), 因为等待平均 7.7 天错过启动段。
2. **"是否出现大阳线"可作为事后质量指标**(出大阳组 39.1%>10% vs 无大阳组 18.2%), 但**不能用于延迟入场**。
3. 豆包的 +21% 无法复现, 且与 +11.1% 的对比口径不一致 → 该结论不应作为定版依据。
**方法论**: 比较两个"入场时点"时, 必须锁定**同一样本集合**(否则是在比较"选出来的票"和"全部票")。
