## 未来函数 oracle（仅诊断，不进入生产）

定义：每个阶段转换后，未来 60 个交易日内是否继续推进到更高阶段。

| 阶段 | 继续推进 | 比例 |
|---|---:|---:|
| S1 → 后续推进 | 16 / 122 | 13.1% |
| S2 → 后续推进 | 20 / 20 | 100.0% |
| S3 → 后续推进 | 14 / 20 | 70.0% |
| S4 → 后续推进 | 3 / 14 | 21.4% |

结论：

- 状态机结构在当前样本内稳定，未再出现 S1→S3 跳档、S4 先于 S3、S5 先于 S4。
- 截断一致性为 0 异常，说明生产状态机只依赖当日及以前数据。
- S1 的 13.1% 和 S4 的 21.4% follow-through 偏低，说明第一版这两个阶段偏“早/宽”；base 版本保留为观察标签，不直接作为买入信号。
- S2→后续推进 100%（样本 20 次）说明放量上 A 的确认质量较高，但样本量仍小。

## 说明

未来函数 oracle 只用于诊断“因果版本是否漏掉后续推进”，不得进入实盘信号或选股。
