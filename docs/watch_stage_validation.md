## 本轮修复

- S1 重武装：仅当 S1 失败回到 S0 后，重新站上 B 连续 2 天且 B 斜率≤+2%，允许再次进入 S1。
- S4 从 S3 起算 30 日，且必须经过 S3。
- S5 使用回踩前高点，S4 后冻结 `s2_high`。
- S2 与 S3 不能同日连续判定，S2 至少保留一天。
- 600199 2020 案例：S1 05-07 → S0 05-11 → **S1 重武装 05-14** → S2 06-22 → S3 06-29 → S4 07-24。

## 说明

未来函数 oracle 只用于诊断“因果版本是否漏掉后续推进”，不得进入实盘信号或选股。
S1 重武装后 follow-through 从 13.1%→35.6%，但仍只作观察标签；S4 的 23.1% 也说明回踩后确认仍需 S5。
